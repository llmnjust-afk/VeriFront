## 1. 预测对象（预先定义）

- **主指标（连续）**：`Risk(s,m) = −ΔSR(s,m)`，其中 ΔSR(s,m)=SR(s,m)−SR(s,F)（plan G1 口径）；
- **辅指标（二值）**：`Fail(s,m) = 1[ΔSR(s,m) ≤ −0.33]`（阈值源自 P1 探索性标准，报告时须说明其探索性出身）；
- 单位：(点实例, 替换模型) 对；同一点实例的多个替换模型为相关观测（聚类处理见 §4）。

## 2. 特征集

- **V（可验证性特征）**：codebook F1–F7（F1–F6 有序 0/1/2，F7 类别）；
- **C（控制变量）**：step_no、剩余预算（12−t+1）、parent stratum（stable_pass/stable_fail/flaky）、role（critical/neutral）、替换模型指示（one-hot）；
- **禁止输入**：任何直接/间接编码"是否依赖前沿模型"的变量、替换实验结果、parent 终局 Y。

## 3. 模型与比较

- **M0（基线）**：仅 C 的正则化线性/层次模型（β 回归或带聚类的 OLS）；
- **M1（主模型）**：V + C；
- **比较**：留出任务上的预测误差差（RMSE）与相关增益（Spearman ρ）、二值任务的 AUROC 增量；
- 复杂模型（梯度提升等）仅作附录敏感性分析，不作主结果。

## 4. 划分与防泄漏

- **任务级留出**：leave-one-task-out CV（10 任务）；P2c 新域任务作独立测试集，不参与任何调参；
- **同一 parent 的步骤不得跨训练/测试**（以 parent_stamp 为聚类单元，训练/测试划分按 parent 分组）；
- 特征标注冻结时间戳必须早于任何 P2b/P2c 结果解盲（记录于 §6）。

## 5. 样本量规划

- 现有：38 点实例 × {mini, ds} 全覆盖 + qwen 信号点 7 实例；
- P2b 新增：全步扫描 2 parent × ~12 步（−2 重放起点）≈ 20–22 点实例 × 3 臂；qwen 对照臂 ~10 点实例；关键点补样 n≥8；
- 目标：**≥60 点实例 × ≥2 模型 ≈ ≥120 (点,模型) 观测**用于 M0/M1 比较；不足时报告功效分析而非强行下结论。

## 7. 判定规则（预先声明）

- 若 M1 相对 M0 在留出任务上 ΔRMSE ≤ 0 且 Δρ ≥ 0.1：支持"可验证性特征有独立预测增益"（H2）；
- 若 M1 ≈ M0：如实报告"当前特征集无增益"，转为探索性分析；
- 所有置信区间用 cluster bootstrap（按 parent 分组重抽样，B=2000）。
