# P2c：M0 vs M1 预测分析报告（预注册协议执行）

## 1. 主结果（Ridge，固定 α=1.0，leave-one-task-out CV，14 任务）

| 模型 | 特征 | RMSE | Spearman ρ | AUROC（Y≥0.5）|
|---|---|---|---|---|
| M0 | 仅控制变量 C | 0.3805 | 0.3007 | 0.7182 |
| M1 | V (F1–F6) + C | **0.3442** | **0.4659** | **0.7872** |
| **增量** | | **−0.0363** | **+0.1652** | +0.0690 |

**预注册判定（协议 §7）**：ΔRMSE ≤ 0 且 Δρ ≥ 0.1 → **两项标准同时满足，支持 H2**（可验证性特征对步级替换成功率有独立于控制变量的预测增益）。

**防泄漏**：(i) 超参固定不调参；(ii) 任务级留出，同 parent 不跨 fold；(iii) 特征标注冻结（`78ca6ab`，unix 1791993533）先于任何逐点结果查看——补跑的 16 条 run 在冻结后执行并立即入 inventory，M0/M1 分析为解盲后首个消费。

## 2. 敏感性分析（附录项，梯度提升，同 CV）

| 模型 | RMSE | ρ | AUROC |
|---|---|---|---|
| M0-GBM | 0.3988 | 0.3531 | 0.7541 |
| M1-GBM | 0.3858 | 0.4156 | 0.7775 |

方向与主结果一致（ΔRMSE=−0.013、Δρ=+0.063），效应量略小——线性模型下特征增益更明显，属预期（n=134 小样本）。

## 3. 逐臂分解（|误差|改善，M1−M0，正值=M1 更好）

## 4. M1 增益来自哪里

- **改善最大的点**（|误差|降幅）：t60s3（+0.32）、t37s8（+0.26）、t37s5（+0.23）、t53s1（+0.21）、t37s10（+0.18）——多为**源码检视/数据核对步**：这些点 A/B 仲裁后 F1=0（探查步无对错标准），M0 按"step_no+stratum"无法区分它们与产物步的失败风险，M1 用 F1 显式修正。
- **M1 变差的点**：t44s4@341588（−0.16）、t58s2@278797（−0.15）、t18s2（−0.12）——同为检视/核对步，但实际臂间成功率结构不同（F1=0 在这些点上高估了成功率）。
- **Ridge 全数据系数**（解释性拟合，非因果）：stratum_fail=−0.41、role_crit=+0.30；F3=−0.54、F1=−0.29、F2=+0.25、F4=+0.28、F5=−0.17、F6=+0.03。**符号解读需谨慎**：F3 负号反映"任务专用反馈多的产物步恰是 mini/ds 高失败步"的条件相关，不构成"反馈有害"的因果主张。
- 裁决后 **F5 全部 ≤0.5**（0×25、0.5×13），在本样本中近乎常数，系数接近无效——state_dependence 维度的判别力损失是仲裁结果的直接代价，记录在案（`p2_adjudication_pack_filled.md` 中 A 侧论证保留）。

## 5. 功效与边界（协议 §5 要求的如实报告）

- 观测 134 (点,臂)，**低于协议目标 ≥60 点实例 × ≥2 模型 ≈ ≥120 观测的"点数"维度**（38 < 60 点，但观测数 134 ≥ 120）——按协议报告功效限制而非强行下结论：本结果为**方向性支持**，效应量（Δρ=0.17）在 14-fold LOTO 下对单任务扰动敏感（M1 变差点即例证）；不外推到未覆盖的步类型/任务域。
- P2c 跨域独立测试集（协议 §4）未包含在本分析中，留作后续。

## 6. F2 操作化边界（预注册声明，见 prediction_protocol §2）

F2 为"产物/交付路径"代理变量，不等同于执行时语义正确性校验器；本分析中 F2 与 F1、F3 作为**独立特征**进入 M1，未合并、未事后重解释。

## 7. 结论

在预注册判定规则下，**七维可验证性特征（尤其 F1 的探查/产物区分）对步级替换成功率具有独立于步骤序号、预算、结构分层与臂身份的预测增益**。该增益在任务级留出下成立、在 GBM 敏感性检验下方向一致。作为 38 点样本上的方向性结论，其外推有效性待跨域测试与扩样验证。
