# P1-CF 主报告：步级反事实替换实验（定稿）— 2026-10-11

**实验问题**：科研 Agent 轨迹中的"关键步"是否构成对前沿模型的**真实能力依赖**（H1a/H1b, Prompt_V2 §0.3.5）。
**方法**：方案 A 确定性重放——消息层从 trace 逐字节重建、文件系统层重执行 parent 前缀步（消耗 0 步预算），在步 t 接管：`resample`（frontier 重采样，重放+继续基线）vs `local_replace`（小模型仅生成步 t，frontier 续跑）。双替换模型：gpt-5.4-mini-2026-03-17（同族 mini）、deepseek-v3.2（异族）。温度 0，n≥2/臂/点。
**选点**：仲裁 gold（κ=0.779 通过门槛）→ 38 点：16 critical_success（成功 run 关键步）、11 critical_failure（失败 run 关键失败步）、11 neutral（每任务×outcome 配额）。203 run 完成执行（补齐后每点每臂 n≥2）。

## 一、主结果

### 1. 臂级成功率（按角色）

| 角色 | resample | mini 替换 | deepseek 替换 |
|---|---|---|---|
| critical（23 点） | 30/55 (0.55) | 26/52 (0.50) | 33/54 (0.61) |
| neutral（15 点） | 7/14 (0.50) | 7/14 (0.50) | 7/14 (0.50) |

- **neutral 对照三臂完全一致（0.50/0.50/0.50）**——替换操作本身既不系统性破坏也不系统性挽救，实验效度良好。
- **critical 点上替换臂不劣于重采样基线**（deepseek 0.61 甚至最高）：15 个 critical_success 点中 9 个 ΔSR≤0（替换不掉链子），**多数"关键步"不构成对前沿模型的真实依赖**。
- 反例（替换有害点）：40 s4、60 s4、60 s6（mini 单侧失败）；18 s2/s3（resample 反而 1/2，见 §3 方差问题）。

### 2. 点级 ΔSR 分布（resample 均值 − 最差替换臂均值）

- crit/succ（15 点）：3 个 −0.50、6 个 0、6 个 +0.25~+0.50 → 均值 +0.05
- crit/fail（8 点）：6 个 0、+0.25（44 s4）、+0.50（5 s2）→ 均值 +0.09
- neut/fail（4 点）：2 个 +0.50（40 s2、58 s2 的 deepseek 单次翻转，flaky 任务噪声）+2 个 0
- neut/succ（3 点）：全 0

### 3. resample 基线的方差问题

85 s1：resample 1/4 vs mini 3/4、ds 3/4（ΔSR=−0.50）；18 s2/s3 同向。**温度 0 不保证 relay 端确定性**，frontier 重采样在部分点上方差大。分析含义：ΔSR 应以 resample 臂（而非 parent 原始结果）为参照系——本报告已如此处理；报告 parent 参照系作为补充。

### 4. 失效模式分层（H1a 的机理细化）

替换臂 72 条记录了接管步 parsed_action 的 run：

| 接管步行为 | 成功 | 失败 |
|---|---|---|
| 正常写代码（capability 路径） | 54 | 50 |
| 格式错误 none（可自愈） | 8 | 9 |
| 过早终结 final | 0 | 1 |

- **capability 失效占主导**（50/60 失败 run ≈ 83%）：小模型写出代码但质量不足以延续成功。
- **protocol 失效占 17%**：格式错误后 47% 在下一步自愈；premature final 罕见（1 例，60 s8 deepseek，跳过 4 步导致 eval 崩溃）。
- 结论：小模型替换的主要瓶颈是**编码能力**而非指令遵循——与"能力前沿"解释一致。

## 二、对假设的初步回答（P1 证据强度：提示性，非确证）

- **H1a（部分否定 → 精细化）**：critical_success 步**作为类别**不构成前沿依赖（替换臂整体不劣）；但存在**点级异质性**——约 1/3 的 cs 点在至少一个替换模型上出现 ΔSR≥+0.25，且 mini（同族）比 deepseek 更易在 cs 点失败（mini 0.50 vs ds 0.61）。"关键步"的标注捕捉了语义重要性，但语义重要性 ≠ 前沿能力需求。
- **H1b（部分支持）**：critical_failure 步的修复是**前沿依赖的**：11 个 cf 点中 8 个完全无法被小模型修复（三臂全败），仅 5 s2 出现 resample-only 修复（1/2）而替换臂 0/2。失败修复比成功维持更依赖前沿能力。
- **方法学产出**：方案 A 重放保真经验收（差异全部为 matplotlib 缓存路径/workdir 路径等环境噪声）；neutral 对照三臂一致证明替换操作无系统性偏倚；protocol/capability 失效分层可量化。

## 三、限制

1. **n=2/臂**：点级 ΔSR 的 ±0.25/0.50 变化处于二项噪声边缘；显著性检验需 n≥4-5（仅对信号点追加，预算 ~40-60 CA）。
2. resample 基线方差（§3）使 ΔSR 参照系本身有噪；候选改进：resample 臂 n=3。
3. relay 端非确定性（temp 0 不严格）与 parent-run 单一性（每点一个 parent）限制外推。
4. 小模型为 API 代理（gpt-5.4-mini / deepseek-v3.2），本地开源 7-8B（Qwen3-8B vLLM，REBUILD PENDING）复验待做。
5. deepseek 定价用 deepseek-v4-flash 代理（下界）。
