# 科研步骤本体（step_ontology）

八类科研语义步骤 + 复合/无法归类规则。对应 Prompt_V2 §3。

## 三层表示

| 层次 | 定义 | 例 |
|---|---|---|
| 事件 Event | Agent 消息、工具调用、工具响应、文件/环境变化 | `tool_call`、`tool_result` |
| 动作 Action | 一次可执行操作（一次 bash、一次 Python 执行、一次文件修改） | 分组规则见 `verifront/traces/steps.py` |
| 科研语义步骤 Scientific step | 相对独立、具科研目的的操作单元，可含多个事件/动作 | "数据清洗"、"执行统计分析" |

**不默认 `1 Action = 1 Scientific step`。** 动作级替换是第一阶段允许的工程手段，报告必须注明粒度。

## 八类标签

| key | 名称 | 判别要点 | 典型验证方式 |
|---|---|---|---|
| retrieval | 检索 | 面向信息源的查找行为 | 引文存在性、原文片段匹配 |
| doc_parse_convert | 文档解析与格式转换 | 格式/结构转换产出 | schema、字段类型、行数守恒 |
| info_extract | 信息抽取 | 从源中抽取结构化信息 | 约束核验、来源定位 |
| tool_args | 工具参数构造 | 为工具调用准备参数 | 类型/取值范围/必要参数检查 |
| code_gen_repair | 代码生成与修复 | 产出或修改可执行代码 | 运行、断言、单元测试 |
| numeric_stats | 数值与统计计算 | 数值计算或统计推断 | 独立重算、量纲检查 |
| analysis_planning | 分析规划 | 决定"接下来怎么做" | 较难确定性验证（记低覆盖） |
| result_interpretation | 结果解释与结论生成 | 从结果到科学结论 | 证据-结论一致性（人工为主） |

## 复合步骤与无法归类

- 一个语义步骤可跨多个动作；映射表必须显式给出动作区间（连续、不重叠）。
- **复合主类规则**：步骤内动作分属多类时，按该步骤的主要科研目的归类，并在 notes 记录次类。
- 允许 `unassignable`：上下文不足以可靠归类时**必须**使用该标签，不得强行凑类。
- 某类在轨迹语料中覆盖不足时如实报告，不强行凑样本。

## 标注流程（P1 试标规模）

1. 两名标注者独立标注同一批候选步骤（P1：50–80 个），互不可见，且**不可见**模型身份、任务成败、检查器得分。
2. 每条标注保存：原始上下文引用、证据片段、归类理由。
3. 计算 Cohen κ 与混淆矩阵（`verifront/annotations/labels.py`）；目标 κ ≥ 0.7。
4. κ 未达标：先分析是本体不合适、上下文不足还是粒度不一致，修订手册后重标；不立即宣布失败。
5. 只有可稳定归类的类型才进入可验证性与替换效应分析。

## 正确性标签（与类型标签分开保存）

- 取值：`correct` / `incorrect` / `uncertain`（附证据；不确定单独统计）。
- 真值优先级：独立测试/重算/核对过的参考答案 > 双人盲评+仲裁 > （避免）LLM 判官单独作真值。
- 代码正常退出 ≠ 科研正确；任务失败 ≠ 某中间步骤必然错误。
