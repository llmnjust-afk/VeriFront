# P2 Batch Operations Assets

Frozen execution records for all P2b batch experiments: one line per counterfactual
run (`scripts/run_cf_point.py ...`), plus the worker templates that executed them
sequentially with per-batch logs.

**Credentials**: worker scripts source `/data/lab/.verifront_env` (600) at runtime;
no API keys are embedded anywhere in this directory.

| Batch file(s) | Worker | Experiment | Report |
|---|---|---|---|
| `scan_cmds.txt` | `run_scan.sh` | §5.1 full-step sweep (99 runs) | `reports/pilot/p2_scan_profile.md`, `p2_scan_stats.md` |
| `fb_cmds.txt`, `fb_cmds_a/b.txt` | `run_fb.sh`, `run_fb1.sh`, `run_fb2.sh` | §5.5 feedback pilot v1 (2×2, 49 runs) | `p2_feedback_intervention_results.md` |
| `fb2v_cmds.txt` | `run_fbv.sh` | §5.5 v2 trigger extension (21 runs) | `p2_feedback_intervention_v2.md` |
| `sfx_cmds.txt` | `run_sfx.sh` | §5.2 suffix takeover (15 runs) | `p2_suffix_analysis.md` |
| `q14_cmds.txt` | `run_fbv.sh` (slot 3) | §5.3 Qwen3-14B-AWQ replication (22 runs) | `p2_q14_analysis.md` |
| `fill8_cmds.txt` | `run_fill.sh` | §5.4 fill-to-n≥8 (27+1 runs) | `p2_sec54_analysis.md` |
| `protretry_cmds.txt` | `run_pr.sh` | §5.4 protocol-retry experiment (16 runs, `# GROUP=RETRY/CTRL`) | `p2_sec54_analysis.md` |
| `qwen_ctl_cmds.txt` | `run_qwen_ctl.sh` | vLLM 8B/14B service control probes | `p2_q14_analysis.md` |

Run-level outcomes for every line are traceable in `reports/pilot/p2_run_inventory.csv`
(756 rows; one row per CF run, keyed by `stamp`), regenerated by
`scripts/p2_reproduce_tables.py` from raw `result.json` files.
